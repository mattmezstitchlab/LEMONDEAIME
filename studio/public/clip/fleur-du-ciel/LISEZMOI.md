# La Fleur du Ciel brodée — données publiques (accord de Matt, 1/11/2026 : « tout est de moi »)

- `la-fleur-du-ciel.m4a` : « La Fleur du Ciel », musique de Matt (composition et enregistrement), AAC aligné à l'échantillon sur le master.
- `clip.json`, `fils-NNN.bin.gz` : format `clip-brode` v1. Une fleur dessinée pour le morceau (pas d'image source), brodée point par point :
  le bouton, la tige, puis le ciel en anneaux dont la couleur suit le moment du morceau ; l'éclosion à l'impact (03:18.255),
  l'arc-en-ciel (03:20.25 → 03:26.25), la Perle (04:02.75). Valeur d'un point : fil 0…44 ; 45 = toile nue ; 128 + fil = demi-croix.
- Lus par `/studio/fleur-du-ciel` (`src/clip/`, configuration `FLEUR`).
